MMV · Minha Melhor Versão — Política de privacidade

O MMV é um planner pessoal de uso exclusivo de Diana Freitas (Diana Freitas ADR). Não é oferecido ao público.

Dados do Google Agenda

Com autorização da própria titular da conta, o MMV lê os eventos da agenda principal para calcular o tempo livre e cria ou atualiza eventos dos blocos de trabalho aprovados no app. Esses dados não são vendidos, compartilhados com terceiros nem usados para publicidade. O uso segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento

As credenciais de acesso ficam guardadas no servidor do MMV, protegidas, e nunca no aparelho. Os registros do planner ficam no banco de dados privado do MMV.

Revogar o acesso

O acesso pode ser desconectado a qualquer momento em Mais › Conexões no app, ou em myaccount.google.com/permissions.
